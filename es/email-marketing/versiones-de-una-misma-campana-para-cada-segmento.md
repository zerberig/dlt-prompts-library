Contexto: Voy a enviar una campaña para promover [tu producto] entre mis clientes. De cada contacto tengo estos datos: [datos disponibles] (edad, ciudad, intereses, historial de compra, preferencias declaradas).
Objetivo: Que cada segmento reciba la versión más relevante para él en lugar de un correo genérico, para aumentar clics y ventas.
Entregable: 1) 3-5 segmentos que pueda armar con mis datos, con el criterio exacto de cada uno. 2) Para cada segmento: asunto personalizado, ángulo del mensaje, beneficio a destacar, imagen o producto sugerido y llamada a la acción. 3) Una versión base para quien no entra en ningún segmento. 4) Cómo comparar los resultados entre segmentos.
Criterios: Personaliza con base en datos reales, no en estereotipos: prioriza intereses declarados y compras previas sobre suposiciones por edad o género. No uses datos que el cliente no sepa que compartió, porque se percibe invasivo.
Formato: Una tabla con las columnas Segmento, Criterio, Asunto, Ángulo, Beneficio y Llamada a la acción; la versión base y la medición en viñetas.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
