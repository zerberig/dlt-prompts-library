Objetivo: Quiero un recurso que mi equipo consulte cada vez que escriba un asunto, para no empezar de cero y probar enfoques distintos.
Entregable: 12 fórmulas de asunto. Para cada una: la estructura con los huecos entre comillas (por ejemplo, "Cómo «resultado» sin «obstáculo»"), 2 ejemplos aplicados a mi negocio, el tipo de correo donde mejor funciona y un riesgo a evitar.
Criterios: Ninguna fórmula garantiza aperturas; presenta cada una como una hipótesis para probar con mi propia lista. Incluye variedad: curiosidad, beneficio, urgencia real, prueba social, pregunta, lista y personalización. Ejemplos de menos de 50 caracteres.
Formato: Una tabla con las columnas Fórmula, Ejemplo 1, Ejemplo 2, Mejor para y Riesgo.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
