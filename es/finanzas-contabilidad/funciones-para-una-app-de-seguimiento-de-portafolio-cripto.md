Objetivo: Quiero un documento de funciones que el equipo de desarrollo pueda estimar y construir por fases, equilibrando facilidad de uso para principiantes y profundidad para usuarios avanzados.
Entregable: 1) La lista de funciones priorizada con el método MoSCoW (debe, debería, podría, no por ahora): conexión con exchanges y billeteras por solo lectura, registro manual, precios en tiempo real, rendimiento y costo promedio, alertas, reportes para impuestos, noticias, modo principiante. 2) Para cada función de prioridad "debe": descripción, criterios de aceptación y dependencias técnicas. 3) Requisitos de seguridad y privacidad: manejo de llaves de API, autenticación, cifrado, qué datos nunca almacenar. 4) Integraciones de datos necesarias y riesgos de cada proveedor. 5) Un plan de 3 fases con alcance de cada una.
