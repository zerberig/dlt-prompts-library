Contexto: Necesito implementar [funcionalidad que necesitas] en un proyecto con [lenguaje y framework]. El proyecto es [tipo de proyecto y licencia] (por ejemplo: producto comercial de código cerrado, proyecto open source con licencia MIT).
Objetivo: Elegir una librería confiable que no se convierta en un problema de mantenimiento, seguridad o licencia.
Entregable: 1) De 3 a 5 librerías candidatas comparadas. 2) La recomendada para mi caso y la segunda opción. 3) Un ejemplo mínimo de uso de la recomendada. 4) Los riesgos de depender de ella y cómo aislarla en mi código para poder cambiarla después.
Criterios: Compara actividad de mantenimiento (último release, issues abiertos), adopción, licencia y compatibilidad con mi proyecto, vulnerabilidades conocidas, peso o dependencias que agrega y calidad de la documentación. Usa búsqueda web si la tienes para verificar el estado actual de cada librería; marca como estimación lo que no puedas confirmar y no inventes nombres de paquetes. Si la librería estándar del lenguaje es suficiente, dilo.
Formato: Tabla comparativa con una columna por criterio; luego la recomendación, el ejemplo en un bloque de código y los riesgos en viñetas.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
