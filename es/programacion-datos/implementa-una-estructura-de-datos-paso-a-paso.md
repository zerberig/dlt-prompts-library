Contexto: Estoy aprendiendo o repasando estructuras de datos. Quiero implementar [estructura de datos] en [lenguaje] (por ejemplo: una cola con lista enlazada o una lista doblemente enlazada).
Objetivo: Entender cómo funciona por dentro y tener una implementación limpia que pueda usar como referencia o en una entrevista técnica.
Entregable: 1) Explicación breve de la estructura y cuándo conviene frente a las alternativas. 2) Implementación completa con las operaciones principales (insertar, eliminar, buscar y las propias de la estructura) y comentarios en las partes no obvias. 3) Tabla de complejidad en tiempo y espacio por operación. 4) Pruebas unitarias con casos normales y de borde (estructura vacía, un solo elemento, elementos repetidos). 5) Un ejemplo de uso y un ejercicio para practicar.
Criterios: Código idiomático del lenguaje y sin recurrir a la versión que ya trae su librería estándar, para que se vea la lógica. Maneja los errores de forma explícita (por ejemplo, sacar un elemento de una cola vacía). Si existe una optimización común, explícala aparte.
Formato: Secciones numeradas; el código y las pruebas en bloques separados.
