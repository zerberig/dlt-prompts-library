Contexto: Necesito el documento de diseño técnico de [tu producto o funcionalidad], que resuelve [caso de uso principal]. Tecnologías: [tecnologías]. Requisitos y restricciones: [requisitos y restricciones].
Objetivo: Un documento que el equipo pueda revisar antes de programar y que sirva de referencia para quien llegue después.
Entregable:
1. Resumen, objetivos y lo que queda fuera del alcance.
2. Diagrama de contexto y diagrama de contenedores o componentes en Mermaid.
3. Descripción de cada componente: responsabilidad, interfaces y tecnología.
4. Flujo de datos del caso de uso principal con un diagrama de secuencia en Mermaid.
5. Modelo de datos y contratos de API principales.
6. Seguridad, observabilidad y manejo de errores.
7. Alternativas consideradas y por qué se descartaron.
8. Plan de implementación por fases y preguntas abiertas.
Criterios: Escribe para un desarrollador que no estuvo en las conversaciones previas: claro, específico y sin relleno. Cada diagrama debe ser código Mermaid válido que se pueda pegar y renderizar.
Formato: Documento en Markdown con encabezados por sección y los diagramas en bloques de código mermaid.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
