Contexto: Quiero diseñar [funcionalidad] para [tu producto]. El usuario principal es [usuario principal] y debe poder [qué debe lograr el usuario].
Objetivo: Validar la experiencia con usuarios antes de programarla en serio, con un prototipo que se pueda abrir y recorrer.
Entregable:
1. Flujo del usuario paso a paso, incluido el camino de error.
2. Lista de pantallas con su propósito, contenido y acción principal.
3. Estados de cada pantalla: vacío, cargando, error y éxito.
4. Un prototipo navegable en un solo archivo HTML con CSS y JavaScript, con datos de ejemplo realistas y clics que lleven de una pantalla a otra.
5. 3 preguntas para una prueba de usabilidad con 5 usuarios.
Criterios: Una acción principal clara por pantalla y textos breves, porque el objetivo es medir si el flujo se entiende. Cumple lo básico de accesibilidad: contraste suficiente, áreas táctiles amplias, etiquetas en formularios y navegación con teclado. Diseño responsivo, pensado primero para móvil.
Formato: Secciones numeradas en texto y el prototipo completo en un solo bloque de código.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
