Contexto: Quiero configurar un asistente personalizado (GPT personalizado, Proyecto de Claude o Gem de Gemini) que reciba un tema y devuelva un prompt de imagen creativo, listo para pegar. Lo usaré para [uso de las imágenes] y mi estilo visual preferido es [estilo visual preferido].
Objetivo: Escribe las instrucciones de sistema de ese asistente.
Entregable: Instrucciones completas que le indiquen al asistente: 1) Combinar el tema con una idea inesperada de una de estas familias: cambio de escala, transformación de material, paradoja temporal, cruce de dimensiones, emoción hecha objeto o física imposible, eligiendo la que mejor sirva al tema. 2) Escribir el prompt como un párrafo fluido de 60 a 120 palabras en este orden: escena y fondo, sujeto, 3 a 5 detalles concretos, técnica o cámara e iluminación con intención emocional, paleta y ambiente. 3) Agregar una versión para Midjourney V8 con solo --ar y, si aplica, --raw o --stylize. 4) Entregar solo el prompt, sin introducciones. 5) Si el usuario lo pide, crear un prompt de video para Veo 3.1 o Kling 3.0 con cinematografía, sujeto, acción, contexto y estilo, más líneas de audio aparte.
Criterios: Las instrucciones deben explicar el porqué de cada regla, porque así el asistente las aplica mejor en casos nuevos. Incluye reglas para describir técnicas en vez de nombrar artistas vivos, marcas o personajes con derechos; poner el texto de la imagen entre comillas y corto; y expresar las exclusiones en positivo. Agrega dos ejemplos breves de entrada y salida.
Formato: Instrucciones en secciones con encabezado, listas para copiar. Entre 300 y 500 palabras.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
