Contexto: Estoy armando una biblioteca de prompts sobre [tema] para [público objetivo].
Objetivo: Encontrar casos de uso concretos que se conviertan cada uno en un prompt reutilizable, no ideas vagas.
Entregable: [cantidad de subtemas] subtemas con formato de herramienta (por ejemplo, para YouTube: "Generador de guiones para videos cortos" o "Generador de títulos para videos"). Para cada uno: el nombre, el problema que resuelve, qué datos tendría que dar el usuario y qué resultado obtendría.
Criterios: Cada subtema debe ser distinto de los demás en tarea o resultado, porque los duplicados disfrazados restan valor a la biblioteca. Cubre etapas distintas del trabajo (planear, crear, mejorar, medir) y prioriza lo que mi público haría cada semana. Si un subtema depende de datos de plataformas o tendencias, indícalo para pedir búsqueda web en el prompt final.
Formato: Tabla con las columnas Subtema, Problema que resuelve, Datos de entrada y Resultado, ordenada de mayor a menor utilidad.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
