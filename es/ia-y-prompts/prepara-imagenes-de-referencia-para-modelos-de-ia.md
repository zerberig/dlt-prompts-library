Contexto: Voy a subir [tipo de imágenes] como referencia a [modelo de IA] (Nano Banana 2, GPT Image 2, Midjourney V8, Veo 3.1 o Kling 3.0) para [qué quiero lograr].
Objetivo: Preparar los archivos para que el modelo lea bien la referencia y el resultado no herede defectos como ruido, compresión excesiva o recortes torpes.
Entregable: 1) Una lista de verificación previa a la carga: formato y peso, resolución y proporción, recorte, fondo, iluminación, ruido y artefactos de compresión. 2) Cómo resolver cada punto con herramientas gratuitas o comunes, en pasos breves. 3) Cuándo conviene mejorar la imagen antes de subirla (escalado, reducción de ruido) y cuándo es mejor dejarla tal cual para no inventar detalles. 4) Un ejemplo de instrucción para acompañar la referencia al subirla.
Criterios: Los límites de archivo y los formatos aceptados cambian seguido: si tienes búsqueda web, consulta la documentación vigente del modelo y marca como estimación lo que no puedas confirmar. Prioriza lo que más afecta el resultado.
Formato: Lista de verificación con casillas, seguida de secciones cortas con encabezado. Máximo 500 palabras.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
