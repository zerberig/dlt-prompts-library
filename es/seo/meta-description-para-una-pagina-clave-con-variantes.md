Escribe 3 meta descriptions para mi página sobre [tema de la página], dirigida a [público objetivo], con la palabra clave principal [palabra clave]. Lo que hace diferente a esta página es: [propuesta de valor].
Cada opción debe tener entre 120 y 155 caracteres para que no se corte en el buscador, incluir la palabra clave de forma natural en la primera mitad, describir con precisión lo que la persona encontrará y cerrar con una invitación a hacer clic. Usa un ángulo distinto en cada una: beneficio, resolución de una duda y dato concreto.
Entrega una tabla con Opción, Texto, Número de caracteres y Ángulo, y dime cuál probarías primero.
