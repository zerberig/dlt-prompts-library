Contexto: Mi sitio es [tu sitio o negocio] y tengo estas páginas sin meta description o con una genérica repetida: [lista de páginas] (URL, tema y palabra clave de cada una).
Objetivo: Quiero que cada página tenga una descripción propia que explique qué ofrece y anime a hacer clic, en lugar de que el buscador elija un fragmento al azar.
Entregable: Una meta description por página, de 120 a 155 caracteres, más una nota breve sobre el ángulo usado.
Criterios: Cada descripción debe ser distinta de las demás, incluso entre páginas parecidas, destacando lo específico de cada una. Incluye la palabra clave de forma natural, un beneficio concreto y una invitación a la acción variada. Mantén el tono [tono de marca]. Señala las páginas que parecen duplicadas o con la misma intención, porque quizá convenga fusionarlas.
Formato: Tabla con URL, Palabra clave, Meta description, Caracteres y Ángulo, lista para copiar a una hoja de cálculo.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
