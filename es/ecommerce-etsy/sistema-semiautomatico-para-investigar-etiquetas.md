Contexto: Tengo [número de anuncios] anuncios en mi tienda de Etsy de [nicho o tipo de productos]. Investigar etiquetas y palabras clave a mano me quita horas y lo hago sin orden. Mi nivel técnico es [tu nivel técnico] (hojas de cálculo, automatizaciones sin código o programación).
Objetivo: Quiero un sistema repetible y parcialmente automatizado para investigar etiquetas, compararlas con la competencia y aplicarlas a mis anuncios, sin violar los términos de uso de la plataforma.
Entregable:
1. La arquitectura del sistema: fuentes de datos (mis estadísticas, la API oficial si aplica, herramientas de investigación de palabras clave), dónde se guarda la información y qué partes se automatizan.
2. Una hoja de cálculo maestra con pestañas y columnas.
3. El flujo semanal paso a paso, indicando qué hace la automatización y qué hago yo.
4. Si mi nivel lo permite, un script o automatización de ejemplo comentado para la parte más repetitiva.
5. Cómo revisar etiquetas de la competencia de forma manual y ética.
Criterios: Usa solo métodos permitidos: la API oficial con su autorización o herramientas que la usen. No propongas extraer datos del sitio de forma masiva, porque viola los términos de uso y puede llevar a la suspensión de la tienda. Si tienes búsqueda web, confirma qué permite hoy la API y qué herramientas siguen activas.
Formato: Secciones numeradas; el código, si lo hay, en un bloque aparte.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
