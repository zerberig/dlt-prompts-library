Contexto: Publico una newsletter para vendedores de Etsy del nicho de [nicho de los vendedores]. Este número trata sobre [tema del número] y quiero incluir esta promoción o novedad: [promoción o novedad].
Objetivo: Un correo que mis suscriptores abran, lean completo y que les deje algo útil para aplicar esa misma semana, para que sigan abriendo los siguientes.
Entregable: 1) 3 opciones de asunto con su texto de vista previa. 2) El correo completo con: introducción breve, 3 consejos prácticos sobre el tema, un caso o ejemplo real (o un espacio marcado «por completar» si no tengo uno), una noticia del sector y la promoción. 3) Una idea para el siguiente número.
Criterios: Consejos específicos, cada uno con un paso concreto. Si incluyes novedades de Etsy, confírmalas con búsqueda web y cita la fecha; no inventes casos de éxito ni cifras. La promoción debe ocupar menos espacio que el contenido útil, para que la newsletter no se sienta como publicidad.
Formato: Correo de 350-500 palabras con subtítulos y párrafos cortos.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
