Escribe textos publicitarios para [tu producto] dirigidos a [público objetivo]. Sus características principales son [características principales] y lo que lo hace distinto de las alternativas es [tu diferenciador].
Necesito tres versiones: una corta de máximo 125 caracteres para un anuncio, una media de 50-80 palabras para una publicación y una larga de 150-200 palabras para una ficha o página de producto. Cada una debe abrir con el problema o deseo del cliente, traducir las características en beneficios concretos y cerrar con una llamada a la acción clara. Usa afirmaciones que se puedan comprobar, sin superlativos vacíos.
Si te falta información esencial, hazme hasta 3 preguntas antes de empezar.
