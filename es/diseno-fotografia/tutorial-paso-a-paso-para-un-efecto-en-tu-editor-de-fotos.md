Objetivo: Poder repetir el resultado por mi cuenta y entender qué hace cada ajuste, no solo copiar valores.
Entregable: 1) Qué características debe tener la foto original para que el efecto funcione. 2) Tutorial paso a paso con el nombre de cada panel o herramienta, el ajuste, un rango de valores de partida y qué observar en la imagen en cada paso. 3) Cómo guardar el resultado como preajuste o plantilla. 4) 3 errores comunes y cómo corregirlos. 5) Una variante más sutil y otra más intensa.
Criterios: Las interfaces cambian con las actualizaciones: si tienes búsqueda web, verifica los nombres actuales de menús y herramientas; si no, indica dónde podrían variar. Si la app tiene funciones de IA que simplifiquen algún paso, menciónalas como alternativa.
Formato: Lista numerada de pasos con subtítulos breves.
