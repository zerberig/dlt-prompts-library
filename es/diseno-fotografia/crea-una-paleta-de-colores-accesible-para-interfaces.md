Contexto: Estoy diseñando [tipo de proyecto] (app, sitio web o tablero) con [color base] como color principal de marca. Quiero que la interfaz transmita [personalidad o ambiente].
Objetivo: Una paleta lista para usar en interfaces que cumpla las pautas de contraste WCAG 2.2 nivel AA, para que el texto y los controles sean legibles para todas las personas.
Entregable: 1) Paleta con primario, secundario, acento, neutros (de 5 a 7 tonos) y colores de estado (éxito, advertencia, error, información), cada uno con HEX y RGB. 2) Tabla de combinaciones de texto y fondo con su relación de contraste y si cumple AA para texto normal (4.5:1), texto grande (3:1) y componentes de interfaz (3:1). 3) Combinaciones que debo evitar. 4) Variante para modo oscuro. 5) Reglas de uso: qué color para botones, enlaces, fondos y alertas.
Criterios: Calcula los contrastes con la fórmula de luminancia relativa e indica que conviene confirmarlos con un verificador de contraste antes de implementar. Los estados no deben depender solo del color: sugiere un ícono o texto que los acompañe.
Formato: Tablas para la paleta y las combinaciones; reglas de uso en viñetas.
