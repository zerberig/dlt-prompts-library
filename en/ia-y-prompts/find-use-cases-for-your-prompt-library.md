Context: I'm building a prompt library about [topic] for [target audience].
Goal: Find concrete use cases that can each become a reusable prompt, not vague ideas.
Deliverable: [number of subtopics] subtopics framed as tools (for YouTube, for example: "Short-Form Video Script Generator" or "Video Title Generator"). For each: the name, the problem it solves, what inputs the user would provide, and what output they'd get.
Criteria: Each subtopic should differ from the others in task or output, because disguised duplicates weaken the library. Cover different stages of the work (plan, create, improve, measure) and prioritize what my audience would do every week. If a subtopic depends on platform data or trends, note it so the final prompt asks for web search.
Format: A table with the columns Subtopic, Problem it solves, Inputs, and Output, ordered from most to least useful.
If any essential information is missing, ask me up to 3 questions before you start.
