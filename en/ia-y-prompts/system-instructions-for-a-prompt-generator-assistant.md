Context: I want to set up a custom assistant (custom GPT, Claude Project, or Gemini Gem) that takes a topic and returns a creative image prompt ready to paste. I'll use it for [use of the images], and my preferred visual style is [preferred visual style].
Goal: Write that assistant's system instructions.
Deliverable: Complete instructions telling the assistant to: 1) Combine the topic with an unexpected idea from one of these families: scale shift, material transformation, time paradox, dimensional crossover, emotion made physical, or impossible physics, choosing whichever serves the topic best. 2) Write the prompt as one flowing 60-120 word paragraph in this order: scene and background, subject, 3-5 concrete details, technique or camera and lighting with emotional intent, palette, and mood. 3) Add a Midjourney V8 version with only --ar and, when useful, --raw or --stylize. 4) Return only the prompt, with no preamble. 5) When the user asks, write a video prompt for Veo 3.1 or Kling 3.0 with cinematography, subject, action, context, and style, plus separate audio lines.
Criteria: The instructions should explain the reason behind each rule, because that helps the assistant apply them to new cases. Include rules to describe techniques instead of naming living artists, brands, or copyrighted characters; keep in-image text short and in quotes; and phrase exclusions positively. Add two short input-output examples.
Format: Instructions in sections with headings, ready to copy. 300-500 words.
If any essential information is missing, ask me up to 3 questions before you start.
