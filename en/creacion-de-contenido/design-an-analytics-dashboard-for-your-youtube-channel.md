Context: I run a YouTube channel about [channel topic], and my main goal is [channel goal]. I want to build the dashboard in [dashboard tool] (for example, Looker Studio, Google Sheets, or a BI tool), and I have access to YouTube Studio and its analytics API.
Goal: I want to see on one screen whether the channel is doing well and get alerts when something changes, without checking every report every day.
Deliverable:
1) The dashboard's 8-10 metrics (for example, views, watch time, average retention, impressions click-through rate, net subscribers, traffic sources), with their definition and why they matter for my goal.
2) The dashboard layout: sections, chart type for each metric, filters (date, format, video), and comparison against the previous period.
3) 4-5 alerts with a suggested threshold (for example, a retention drop in the first 30 seconds) and what to check when they fire.
4) How to connect the data: source, refresh frequency, and known limitations.
5) A checklist for the weekly review using the dashboard.
Criteria: Favor a few actionable metrics over many decorative ones. Fit the thresholds to my channel's size and explain how to recalibrate them. If you have web search, check which metrics the YouTube Analytics API exposes today. Flag as an estimate any figure you can't back up with a source.
Format: Numbered sections; metrics and alerts as tables.
If any essential information is missing, ask me up to 3 questions before you start.
