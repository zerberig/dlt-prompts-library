Context: I want to automate tasks on my YouTube channel using [automation tool] (for example, a no-code workflow platform). The tasks I want to automate are: [tasks to automate]. My technical level is [your technical level].
Goal: Have 2–3 useful automations running this week and understand how to maintain them.
Deliverable: A step-by-step guide for each automation: trigger, actions, data passed between steps, how to test it, and what to do if it breaks. Include examples such as notifying my social channels or email list when I publish a video, saving new comments to a sheet so I can reply, or building a weekly metrics report.
Criteria: Use the tool's official YouTube connection. If you have web search, confirm the tool's current features and limits, including its free plan, and flag anything you can't confirm. If a task can't be automated with that tool, say so and suggest an alternative.
Format: One section per automation with numbered steps and, at the end, a table of common problems and fixes.
If any essential information is missing, ask me up to 3 questions before you start.
