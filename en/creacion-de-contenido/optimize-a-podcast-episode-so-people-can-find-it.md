Context: I host a podcast about [podcast topic] for [target audience]. Here is the summary or transcript of the episode I'm about to publish: [episode transcript or summary].
Goal: I want the episode to show up when someone searches its topic on podcast apps, on YouTube, and in search engines.
Deliverable: 1) The 5 most relevant keywords or search phrases for the episode, with the intent behind each. 2) 3 episode title options that include the main phrase naturally. 3) A 120-200 word description with the keyword in the first lines, the points covered, and a call to action. 4) Timestamped chapters, if the transcript includes timing. 5) Recommendations for publishing the transcript and using it for search.
Criteria: Write for people first: clear, honest titles without keyword stuffing, because platforms penalize forced text. If you have web search, check how each platform indexes titles and descriptions and flag anything you can't confirm as an estimate.
Format: Numbered sections with headings; titles and description ready to copy.
If any essential information is missing, ask me up to 3 questions before you start.
