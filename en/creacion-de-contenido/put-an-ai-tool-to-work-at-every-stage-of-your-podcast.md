Context: I produce a podcast about [podcast topic] and have access to [tool or product]. This is how I produce each episode today: [your current process].
Goal: Save hours per episode and improve promotion by getting more out of what I already have, without losing the show's voice.
Deliverable: A stage-by-stage map of the process (research, scripting, recording, editing, publishing, promotion, audience relationship). For each stage: 1–3 concrete uses of the tool, how to set them up, how much time it could save, and what a person should review before publishing. Close with the 3 uses that would deliver the most impact for the least effort.
Criteria: Suggest realistic uses based on features the tool actually has; if you're not sure a feature exists, say so. Flag time savings as estimates.
Format: A table with the columns Stage, Use, How to set it up, Estimated savings, Human review; then the top-3 list.
If any essential information is missing, ask me up to 3 questions before you start.
