Context: I sell [your product] on Etsy. My current title is [current title] and I use these tags: [current tags]. I know Etsy listings don't use hashtags the way social media does; what counts are the listing tags.
Goal: I want the title, tags, attributes, and description to work as one system, covering more distinct searches without repeating the same words in every field or hurting readability.
Deliverable: 1) A diagnosis of my current tags: which repeat the title, which are too generic, and which are worth keeping. 2) A complete new tag set. 3) How to reflect the main ideas naturally in the description, with 2 example sentences. 4) Which listing attributes to fill in to cover searches that don't fit in the tags.
Criteria: Use multi-word phrases a buyer would actually type, spread across product type, style, occasion, recipient, and material. If you have web search, confirm how many tags and characters Etsy allows today.
Format: A table with the columns Tag, Characters, Search type, and Keep or replace; then sections 3 and 4 as bullets.
If any essential information is missing, ask me up to 3 questions before you start.
