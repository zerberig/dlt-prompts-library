Context: I run an Etsy shop selling [niche or product type]. This is a listing I want to improve:
[current title, tags, and description]
Goal: I want the listing to show up in more relevant Etsy searches and give visitors clear reasons to buy.
Deliverable:
1. A short diagnosis: what works and what's hurting the current listing's visibility.
2. 15-20 search phrases a real buyer would use, grouped by intent (gift, use, style, occasion).
3. An optimized title plus 2 alternatives.
4. A full set of tags that doesn't repeat words the title already covers.
5. A rewritten first paragraph for the description.
6. Recommendations for photos, attributes, and category.
Criteria: Favor specific multi-word phrases over generic, highly competitive terms. The title should read naturally to a person, not like a keyword dump. If you have web search, check Etsy's current character and tag limits and its current SEO guidance. Don't present guesses about the algorithm as facts, and flag any search-volume figure you can't back with a source as an estimate.
Format: Numbered sections matching the deliverable; tags in a table with the columns Tag, Characters, and Search intent.
If any essential information is missing, ask me up to 3 questions before you start.
