Context: I sell [your product] on [marketplace]. My listing gets roughly [monthly views and sales] and I want to improve conversion.
Goal: I want a testing plan that shows with data which changes increase sales, instead of changing everything at once and guessing.
Deliverable:
1. The listing elements that can be tested (main photo, title, price, shipping, description, variations, video), ranked by likely impact and ease.
2. For the first 3 tests: hypothesis, version A and version B, primary metric, and supporting metrics.
3. How to run tests if the platform has no native A/B feature (for example, alternating versions over comparable periods) and which outside factors to control for, such as seasonality, paid ads, or discounts.
4. How much time and how many views I need to draw conclusions at my volume, explained in plain language.
5. A test log template.
Criteria: Be honest about the limits: with low traffic, some results will be directional rather than statistically conclusive, and you should say so. If you have web search, check whether the platform offers any testing tool today. Flag any figure you can't back with a source as an estimate.
Format: Numbered sections; the template as a table with the columns Test, Dates, Version, Views, Sales, Conversion rate, and Conclusion.
If any essential information is missing, ask me up to 3 questions before you start.
