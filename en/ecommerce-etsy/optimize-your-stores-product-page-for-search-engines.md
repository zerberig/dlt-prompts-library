Context: I run my own online store for [your business]. I want to optimize the page for [your product] around the main search phrase [main keyword].
Goal: Get the page showing up in search engines for relevant queries, with copy that converts the people who land on it.
Deliverable:
1. Title tag and meta description.
2. H1 heading.
3. A 250-400 word product description with H2 subheadings.
4. 5-8 secondary keywords and related questions the page should cover.
5. Alt text for 3 product photos.
6. Internal linking suggestions.
Criteria: Write for the person first and the search engine second: use the main keyword naturally in the title tag, the H1, and the first paragraph, without overusing it. Include product details that aren't in the manufacturer's copy, since duplicate text competes poorly. If you have web search, look at what the top results for that phrase show today, and flag any volume figure you can't back with a source as an estimate.
Format: Numbered sections matching the deliverable; title tag and meta description with their character counts.
If any essential information is missing, ask me up to 3 questions before you start.
