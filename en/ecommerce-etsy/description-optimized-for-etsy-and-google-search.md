Context: I sell [your product] on Etsy. The main keywords I want to rank for are: [main keywords]. This is my current description: [current description].
Goal: Rewrite the description so it helps the listing show up in both Etsy search and Google, without reading like it was written for robots.
Deliverable: 1) The rewritten description. 2) A table of the keywords used and where they appear. 3) 3 suggestions for the title and tags that reinforce the description.
Criteria: The first 160 characters should sum up what the product is, who it's for, and its main benefit, including the most important keyword, because that part is often shown as the preview. Work in the other keywords and their synonyms naturally, without overusing them. Conversational tone. Don't claim exactly how Etsy's algorithm works; if you have web search, check Etsy's current official SEO guidance.
Format: Description in short paragraphs with bullets; then the table and the list.
If any essential information is missing, ask me up to 3 questions before you start.
