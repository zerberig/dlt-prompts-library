Context: I sell [product type] on [your shop or platform] and every description is written differently. I want to apply a template to [number of products] products, and this is their data: [product data].
Goal: I want a description structure that balances story and practical facts, so every listing feels like the same brand and buyers always find information in the same place.
Deliverable: 1) A template with fixed blocks (a 1-2 sentence emotional opening, key benefits, specifications, customization and shipping, care, closing) and the ideal length for each block. 2) A short guide on how much story versus how many facts to use by product type. 3) The full descriptions for my products with the template applied. 4) For each product, an alternate opening for [season or special occasion] I can swap in when that date comes.
Criteria: Story is for connecting and facts are for deciding: the first sentence should spark interest and the specs should be scannable at a glance. Use only the data I gave you.
Format: The template with block names in bold; each description separate, with the product name as its heading.
