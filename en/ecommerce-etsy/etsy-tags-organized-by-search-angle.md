Context: I sell [your product] on Etsy and this is my listing title: [listing title]. My buyers are usually [target audience] and they buy it for [occasions or uses].
Goal: Use every tag on the listing so it shows up in searches beyond the ones the title already covers.
Deliverable: The full set of tags Etsy allows, spread across 5 angles: what the product is, function or practical use, occasion or recipient, style or aesthetic, and material or distinctive feature. Then 5 backup tags to test in a second version.
Criteria: Use web search if you have it to confirm the current number of tags and character limit; if not, use 13 tags of up to 20 characters. Each tag should be a multi-word search phrase in the language my buyers search in. Avoid repeating exact title phrases, because they waste space, and avoid trademarked brands or characters.
Format: A table with the columns Tag, Angle, Characters, and Search it would capture; then the backup tags as a list.
If any essential information is missing, ask me up to 3 questions before you start.
