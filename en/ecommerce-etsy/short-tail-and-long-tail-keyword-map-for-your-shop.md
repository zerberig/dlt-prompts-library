Context: I run an Etsy shop selling [your niche or type of products]. My main sections or collections are [your sections or collections].
Goal: I want to cover both broad searches and specific searches from buyers who already know what they want, without my listings competing with each other for the same phrases.
Deliverable: 1) A brief explanation of the difference between broad (short-tail) and long-tail keywords, and when each makes sense on Etsy. 2) For each section: 2-3 broad keywords and 6-8 long-tail ones, classified by intent (gift, occasion, style, material, recipient, personalization). 3) A suggested assignment: which phrases go in the section name, which in titles, and which in tags, making sure no two listings target the same main phrase. 4) How to validate the phrases using search suggestions and my shop stats.
Criteria: Long-tail phrases should sound like real searches, in my buyers' language. If you have web search, use it to check trending terms, and flag as an estimate any figure you can't back up with a source, such as search volumes.
Format: One table per section with the columns Keyword, Type, Intent, and Where to use it.
If any essential information is missing, ask me up to 3 questions before you start.
