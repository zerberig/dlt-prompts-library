Context: I run an Etsy shop selling [niche or product type] and want to spend about [daily or monthly budget] on Etsy Ads (formerly Promoted Listings). My best-selling or best-photographed products are: [candidate products].
Goal: I want to set up and manage the campaign so whatever I spend can be traced to sales, and to know when to scale up, scale down, or pause.
Deliverable:
1. A step-by-step setup guide based on the current interface.
2. Criteria for choosing which listings to promote and which to exclude.
3. How to prepare each listing before paying for traffic (photos, title, price, reviews).
4. A review schedule for the first 4 weeks, with the metrics to check at each review.
5. Decision rules: when to raise the budget, when to drop a listing, and when to stop the campaign.
Criteria: If you have web search, check how Etsy Ads work today (budget options, control over listings and keywords, how you're charged) and flag anything you can't confirm. Calculate return using net margin, not gross sales, and don't promise results.
Format: Numbered sections; the decision rules in a table with the columns Signal, What it means, and What to do.
If any essential information is missing, ask me up to 3 questions before you start.
