Context: I sell [your product] on Amazon to [target audience]. Features and specs: [features and specs]. Keywords I want to include: [keywords].
Goal: Bullet points are what many shoppers read before deciding, so I want each one to sell a clear benefit instead of repeating the spec sheet.
Deliverable: 5 bullet points in order of importance to the buyer. Each opens with a short phrase naming the benefit, followed by the feature that supports it and a concrete detail (size, material, or use). Also, an alternative version of the first bullet and, for each bullet, the buyer question it answers.
Criteria: Benefit first, feature second. Work the keywords in naturally without repeating them. Avoid health claims, absolute guarantees, or comparisons with other brands, because they can break Amazon's policies. If you have web search, check the current character limit for bullet points.
Format: A numbered list with the 5 bullets; then the alternative and a short table of the question each bullet answers.
If any essential information is missing, ask me up to 3 questions before you start.
