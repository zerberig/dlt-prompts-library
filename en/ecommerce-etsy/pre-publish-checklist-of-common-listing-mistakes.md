Context: I'm about to publish a listing for [your product] on Etsy. This is my draft: [title, tags, and description].
Goal: I want to catch the most common title and SEO mistakes before publishing, so I don't lose visibility or sales to easy-to-fix problems.
Deliverable: 1) A checklist of 12 to 15 common mistakes (keyword stuffing, repeated words, terms buyers don't use, key information buried at the end of the title, wasted tags, empty attributes, a description that doesn't answer basic questions, and others), each with why it hurts and how to fix it. 2) A review of my draft against that checklist: which mistakes it has and a corrected version of each affected element.
Criteria: Explain each mistake in plain language with a short before-and-after example. If you have web search, compare the list with Etsy's current guidance, and don't present algorithm myths as facts.
Format: The checklist as a table with the columns Mistake, Why it hurts, and How to fix it; then the review of my draft with the corrected elements.
If any essential information is missing, ask me up to 3 questions before you start.
