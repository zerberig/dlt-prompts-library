Context: I sell [your product] to [target audience]. Its main features are: [features and specs]. The doubts I hear most before a purchase are: [common objections or questions].
Goal: A description that persuades and, at the same time, clears up the doubts that are currently stalling sales.
Deliverable: A complete product description plus a short "Before you buy" block that answers each objection.
Criteria: Open with the main benefit in one sentence. Translate every feature into what the customer gains. Answer objections with concrete facts (dimensions, materials, warranty, shipping times) instead of generic reassurance. If an objection has no data to answer it, flag it so I can fill in the facts rather than inventing them.
Format: A 1-2 sentence opening, 4-6 benefit bullets, a details paragraph, and the objections block in question-and-answer form. 180-280 words.
If any essential information is missing, ask me up to 3 questions before you start.
