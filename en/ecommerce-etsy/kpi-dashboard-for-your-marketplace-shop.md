Context: I sell [product type] on [marketplace] and have been selling for [time selling]. Right now I look at my numbers with no system and don't know what to check first.
Goal: I want a simple dashboard I can update weekly in a spreadsheet to spot which listings are underperforming, and at which stage (visibility, interest, or conversion).
Deliverable:
1. 8 to 12 indicators grouped into four blocks: traffic, conversion, profitability, and customer satisfaction.
2. For each indicator: what it measures, its formula, where the data comes from (marketplace dashboard or my own records), and how often to review it.
3. The spreadsheet layout: tabs, columns, and which chart to use for each block.
4. A reading guide: which combination of signals points to each common problem (for example, lots of views but few sales) and what to check first in each case.
Criteria: Favor indicators I can calculate with data the marketplace actually provides; if you have web search, confirm which metrics its seller dashboard shows today. Include fees and shipping in profitability, because gross sales are misleading. Flag any benchmark values as estimates; don't invent industry averages.
Format: Numbered sections matching the deliverable; indicators in a table with the columns Indicator, What it measures, Formula, Data source, and Frequency.
If any essential information is missing, ask me up to 3 questions before you start.
