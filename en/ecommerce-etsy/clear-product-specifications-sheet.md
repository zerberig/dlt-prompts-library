Context: I sell [your product] on [your shop or platform]. This is the data I have: [dimensions, weight, materials, and other technical details].
Goal: I want a spec sheet that lets buyers decide without having to message me and that reduces returns caused by mismatched expectations.
Deliverable: 1) An organized specifications section: dimensions (in inches and centimeters), weight, materials, finishes, capacity or compatibility, what's in the package, care, and production time. 2) A size reference sentence comparing it to an everyday object. 3) A list of missing details buyers usually ask about for this type of product.
Criteria: Clear language with no jargon; if a technical term is necessary, explain it in a few words. Use only the data I gave you: don't invent measurements or certifications.
Format: A list with the label in bold and its value (for example, "Material: 100% cotton"), ready to paste; then the size sentence and the list of missing details.
If any essential information is missing, ask me up to 3 questions before you start.
