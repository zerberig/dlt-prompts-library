Context: I want to design a course on [course topic] for [course audience] where learning revolves around real or realistic cases rather than theory.
Goal: Let participants practice the decisions they'll face on the job.
Deliverable: A structure of 5-8 modules; for each: objective, central case (situation, protagonist, dilemma, and data), analysis questions, an interactive activity, suggested supplementary materials (reading, short video, or template), and assessment. Fully write the first module's case in 300-400 words, ready to hand to students.
Criteria: Cases set in contexts relevant to my audience, with open-ended decisions that have more than one defensible answer. If a case is based on a real company, note which facts need verification; if it's fictional, say so.
Format: A module table with the columns Module, Objective, Case, Activity, and Assessment; then the full case.
If any essential information is missing, ask me up to 3 questions before you start.
