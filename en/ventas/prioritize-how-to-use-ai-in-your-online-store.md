Context: I run an online store selling [your product] on [your store platform], with a team of [team size] people. My main problems right now are [current problems] (for example, lots of repeat questions, incomplete listings, or few repeat purchases).
Goal: Choose the AI use cases that will most improve the customer experience and operations, starting with the ones that deliver quick wins.
Deliverable: 8 to 10 use cases (support assistant, recommendations, smart search, listing generation, review analysis, inventory forecasting, and personalized emails, among others). For each: the problem it solves, how to implement it with available tools, effort, approximate cost, and expected impact. Then a 3-phase roadmap.
Criteria: Prioritize based on my actual problems. Include the risks of each use case (errors, privacy, brand voice) and when a person should review the output. If you have web search, check current tools and pricing and flag anything that is an estimate.
Format: A table with the columns Use case, Problem, Implementation, Effort, Cost, and Impact; then the roadmap.
If any essential information is missing, ask me up to 3 questions before you start.
