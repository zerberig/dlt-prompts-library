Context: I want to apply for [target job title] roles in [industry]. These are the skills I already have: [your current skills].
Goal: Know which skills employers value most for this role, which ones I'm missing, and how to prove the ones I have.
Deliverable: 1) 10-12 skills ranked by importance, split into hard and soft skills. 2) For each, a concrete example of what it looks like day to day and how to prove it on a resume or in an interview. 3) My gap: which ones I have, which I partly have, and which I'm missing, with one concrete action to close the top 3.
Criteria: Base the ranking on what real job postings for this role ask for. If you have web search, use it to check current information, and flag as an estimate any figure you can't back with a source.
Format: A table with the columns Skill, Type, Priority, What it looks like at work, How to prove it, and My level; then the gap-closing plan as bullets.
If any essential information is missing, ask me up to 3 questions before you start.
