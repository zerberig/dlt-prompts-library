Context: I'm targeting [target job title] roles in [industry]. Optional: here are 2-3 real postings I'm interested in: [reference job postings].
Goal: Know which terms recruiters and automated filters look for in this role, so I can use them on my resume and LinkedIn profile.
Deliverable: 20-25 keywords grouped into technical skills, tools or software, methodologies or certifications, and competencies. For each: how common it is in postings for this role (high, medium, low), synonyms or variants worth using too, and where to place it (headline, summary, experience, skills).
Criteria: If I paste postings, prioritize the terms that repeat across them. If not, base frequency on what's typical for the role and flag it as an estimate. Include acronyms alongside the spelled-out form, because some filters look for one and some for the other. Remind me to use only the ones that reflect real experience.
Format: A table with the columns Keyword, Group, Frequency, Variants, and Where to place it.
If any essential information is missing, ask me up to 3 questions before you start.
