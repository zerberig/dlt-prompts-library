Context: My current resume has a visual design (columns, icons, skill bars, tables). Here's its text: [your resume text]. I use it to apply for [target job title] roles.
Goal: Have a second version that applicant tracking systems (ATS) can read without losing information, to use on job portals; I'll keep the designed version for sending directly to people.
Deliverable: 1) The full ATS version of the resume. 2) A list of elements in the original design that commonly cause parsing errors and how you resolved them. 3) Recommendations on file format, font, and file name.
Criteria: Single column, standard headings (Experience, Education, Skills), consistent date format, skills as text instead of bars or percentages. Keep all the content without changing any facts. If something from the original design doesn't make sense as text, mark it "review".
Format: The resume as text with Markdown headings, followed by sections 2 and 3 as bullets.
If any essential information is missing, ask me up to 3 questions before you start.
