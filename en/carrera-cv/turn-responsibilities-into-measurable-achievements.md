Context: These are bullets from my resume that read like a task list: [your current bullets]. I'm targeting [target job title] roles.
Goal: Make every bullet show the impact of my work, not just what I did.
Deliverable: For each original bullet, 3 rewritten versions that use different action verbs and highlight different angles (result, scale, process improvement). Under each group, one line explaining what changed and, if a metric is missing, a specific question to help find it (for example, "How many clients did you handle per month?").
Criteria: Structure: action + what you did + result. Don't invent numbers: if I don't have the figure, use "X" as a placeholder and the question helps me fill it in. Bullets of 2 lines max, using the vocabulary of [target job title].
Format: For each bullet: Original, three numbered versions, explanation, and metric question.
If any essential information is missing, ask me up to 3 questions before you start.
