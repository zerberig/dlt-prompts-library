Context: I want to set up an AI assistant (for example, a custom GPT, a Claude Project, or a Gemini Gem) for [who will use it] (for example, graduates of my program, clients of my career-coaching service, my own search). It will focus on [type of roles] roles in [city or country].
Goal: Have the assistant guide each person from defining what job they want all the way to applying, with useful, consistent conversations.
Deliverable:
1) The assistant's full system instructions: purpose, tone, how it opens the conversation, what information it asks the user for and in what order, and the stages it covers (profile and goal, finding openings, resume, cover letter, interview, follow-up).
2) Behavior rules: what it does when information is missing, how it avoids making up job or salary data, and when it recommends human help (career counselor, employment lawyer).
3) Five test scenarios with the user's message and how the assistant should respond.
Criteria: Clear instructions phrased in the positive, written for a current model that follows directions literally. The assistant should ask for confirmation before rewriting whole documents and should never promise hiring outcomes.
Format: The system instructions in a block ready to copy; rules and scenarios in numbered sections.
If any essential information is missing, ask me up to 3 questions before you start.
