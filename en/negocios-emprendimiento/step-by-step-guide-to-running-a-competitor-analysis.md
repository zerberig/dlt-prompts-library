Context: I run [your business] and I mainly compete on [how you compete] (price, quality, service, location, specialization). I know about these competitors: [competitors you know].
Goal: I want to learn to run a competitor analysis myself that I can repeat every quarter, instead of relying on assumptions.
Deliverable: 1) A 6-to-8-step process, from identifying direct and indirect competitors to turning findings into decisions. 2) For each step, free or low-cost sources to find information (website, social media, customer reviews, active ads, buying as a mystery shopper, etc.). 3) A template with the fields I should record for each competitor. 4) How to sum it all up in my own SWOT with 3 concrete actions.
Criteria: Everything should use public information and ethical methods. Tailor the examples to my type of business. The whole process should be doable in one week.
Format: Numbered steps with bullets; the template as a table with Field, What to record, and Where to find it.
If any essential information is missing, ask me up to 3 questions before you start.
