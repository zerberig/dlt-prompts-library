Context: We're launching [your SaaS product] for [ideal customer]. It solves [problem it solves], and the pricing model is [pricing model].
Goal: I want to know, with data rather than gut feeling, whether the launch is working, what to adjust, and when to double down or change course.
Deliverable: A measurement framework in 3 stages (days 1–30, 31–60, and 61–90). For each stage: the key question we need to answer, 3 to 5 metrics (acquisition, activation, usage, retention, and revenue), how to calculate each one, a ballpark target, and a warning sign. Also define the most likely activation event for my product and suggest a survey question to gauge product-market fit.
Criteria: Fewer, better-chosen metrics: I'd rather have 12 well-defined ones than 40 generic ones. For each stage include a decision rule like "if X is below Y, review Z". If you have web search, use recent benchmarks for the targets; flag as an estimate any figure you can't back up with a source.
Format: One table per stage with the columns Metric, How it's calculated, Ballpark target, and Warning sign; then the decision rules as bullets and a list of tools or events I need to set up to measure all of this.
If any essential information is missing, ask me up to 3 questions before you start.
