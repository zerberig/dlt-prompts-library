Context: I want to start meditating to work with [emotion, mindset, or goal] (for example: stress before presentations, a racing mind after work, trouble concentrating). My meditation experience is [experience level] and I can spend [minutes per day] on it.
Goal: A short, progressive plan I can stick with that helps me notice changes in how I handle that state.
Deliverable: 1) A 3-week plan with each day's practice (breathing, body scan, mindfulness, visualization, or affirmations), gradually increasing the duration. 2) The full script for a 5-minute guided session to use when that state shows up. 3) A simple way to log how I feel before and after.
Criteria: Clear, beginner-friendly instructions in everyday language, with no promised outcomes. Include what to do if my mind wanders or a practice feels uncomfortable. If what I describe sounds persistent or affects my daily life, recommend that I seek support from a mental health professional.
Format: A table with the columns Week, Practice, Duration, and Focus; the script in a separate block.
