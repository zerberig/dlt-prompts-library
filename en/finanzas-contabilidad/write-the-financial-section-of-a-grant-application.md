Context: I represent [your organization's name] and I'm applying to [grant program or funder]. The project is [brief project description], and this is the budget: [project budget], of which we're requesting [amount requested].
Goal: I want the review committee to see that every dollar is justified, the project is viable, and the organization knows how to manage funds.
Deliverable: 1) The budget narrative (300–450 words): need for the funds, use by line item, link to project outcomes, and sustainability after the grant. 2) A justification table by line item. 3) A paragraph on financial controls and accountability. 4) The 3 questions a reviewer would likely ask about the budget, with suggested answers.
Criteria: Tie each line item to a specific activity or outcome, because reviewers reject amounts with no clear link to impact. Use only the figures I gave you and point out inconsistencies if you see any. Clear, professional tone, without grandiose adjectives.
Format: Narrative in paragraphs, a table with the columns Line item, Amount, % of total, and Justification, and the questions as a numbered list.
If any essential information is missing, ask me up to 3 questions before you start.
