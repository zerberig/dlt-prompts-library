Context: We make [your tool's name], an online invoicing tool for [your tool's users] (freelancers, small businesses, etc.). Its main features are: [main features].
Goal: I want a new user to send and get paid on their first invoice without contacting support, and then discover the features that save them time.
Deliverable: 1) A 5–7 step quickstart, from creating an account to sending the first invoice. 2) Short articles for each main feature: what it's for, the steps, and a practical tip. 3) A troubleshooting section with the 8 most likely errors and how to fix them. 4) FAQs about payments, reminders, taxes on invoices, and exporting reports.
Criteria: Write in second person, with short sentences and an action verb at the start of each step. Mark where each screenshot would go with a note in parentheses. Invoicing tax rules vary by country: instead of stating them, tell users where to check local requirements.
Format: Sections with headings, steps as numbered lists, and troubleshooting as a table with the columns Problem, Likely cause, and Fix.
If any essential information is missing, ask me up to 3 questions before you start.
