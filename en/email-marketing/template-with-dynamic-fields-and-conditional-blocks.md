Goal: Send one email that feels written for each person, using the personalization my platform supports.
Deliverable: 1) The full email with dynamic fields written as {{first_name}} or {{last_purchase}}. 2) Fallback text for each field in case the data is missing. 3) 2-3 conditional blocks (for example, different content by purchase category or customer type), with the logic explained in plain language. 4) A checklist for testing the template before sending.
Criteria: Personalization should feel helpful, not invasive: use data customers would expect us to have. The email must read well even if every field comes up empty. If you know my platform's tag syntax, adapt to it; if not, use generic notation and tell me.
Format: The email in its own block; a field table with the columns Field, Data source, and Fallback text; the conditional blocks and checklist as bullets.
