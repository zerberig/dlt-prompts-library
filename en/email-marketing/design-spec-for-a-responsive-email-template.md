Context: I need an email template for a [type of business] that I'll mainly use for [template use] (newsletter, promotions, launches) in [email platform]. My visual identity: [brand colors and fonts].
Goal: Have a clear brief to build the template in the editor or hand it to a designer, so it looks good on any device and doesn't hurt deliverability.
Deliverable: 1) The module structure from top to bottom (header, hero image, content blocks, product, testimonial, call to action, footer) with the job of each one. 2) Specs for width, fonts and sizes, buttons, spacing, and images. 3) Accessibility and dark mode rules. 4) A checklist to run before using it.
Criteria: Mobile-first design, a single column on small screens, easy-to-tap buttons, and live text instead of text inside images, because image-only emails land in the inbox less often and can't be read when images are blocked. Alt text on every image, plus the business address and an unsubscribe link in the footer.
Format: Sections with headings and bullets; the specs in a table with the columns Element, Spec, and Reason.
If any essential information is missing, ask me up to 3 questions before you start.
