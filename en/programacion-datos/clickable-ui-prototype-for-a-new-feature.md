Context: I want to design [feature] for [your product]. The main user is [main user], and they need to be able to [what the user must accomplish].
Goal: Validate the experience with users before building it for real, using a prototype people can open and click through.
Deliverable:
1. The step-by-step user flow, including the error path.
2. A list of screens with their purpose, content, and primary action.
3. States for each screen: empty, loading, error, and success.
4. A clickable prototype in a single HTML file with CSS and JavaScript, with realistic sample data and clicks that move between screens.
5. 3 questions for a usability test with 5 users.
Criteria: One clear primary action per screen and short copy, because the point is to measure whether the flow makes sense. Cover accessibility basics: sufficient contrast, generous tap targets, form labels, and keyboard navigation. Responsive, mobile-first design.
Format: Numbered text sections and the complete prototype in a single code block.
If any essential information is missing, ask me up to 3 questions before you start.
