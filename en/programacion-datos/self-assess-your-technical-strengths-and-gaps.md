Context: I'm [your role and current level] and I work mainly with [your stack or technical area]. I want to reach [the next level or role you're aiming for].
Goal: Run an honest self-assessment of my skills so I know where to focus my learning over the next few months.
Deliverable: 1) A matrix of 10 to 15 competencies relevant to my goal, both technical and non-technical (for example: system design, testing, communication, estimation). 2) For each one, a 1-to-4 scale with an observable description of each level. 3) 2 to 3 reflection questions per competency that help me place myself using evidence from my actual work.
Criteria: Describe each level with concrete behaviors ("reviews others' PRs and catches design problems"), not adjectives, so I can rate myself without guessing. For every competency, include one question that asks me for a recent example as evidence.
Format: One overall table with the columns Competency, Level 1, Level 2, Level 3, and Level 4; the questions below it, grouped by competency. At the end, instructions for picking my top 3 priorities from the results.
If any essential information is missing, ask me up to 3 questions before you start.
