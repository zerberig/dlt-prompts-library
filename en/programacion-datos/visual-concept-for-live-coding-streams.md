Context: I'm going to live-stream coding sessions on [streaming platform] with a relaxed "Code & Chill" vibe. My channel is called [your channel name] and the visual style I'm after is [desired visual style] (for example: dark minimalist, cozy with warm tones, retro).
Goal: A complete visual concept I can build in my streaming software or hand off to a designer.
Deliverable: 1) Main scene layout at 1920×1080: approximate position and size of the code editor, webcam, chat, and a bar showing today's topic. 2) A 5-color HEX palette with each color's use, and suggested fonts (including a monospace one for code). 3) A subtle, looping background animation, described so it doesn't distract. 4) Extra scenes for starting, break, and ending, with the text for each. 5) Editor theme and font-size settings so the code is readable on a phone.
Criteria: Prioritize code readability and visual comfort for long sessions, with enough contrast to be accessible. Use only assets I can make myself or that are freely licensed.
Format: Numbered sections, the palette in a table with Color, HEX, and Use, and a text or ASCII sketch of the layout.
If any essential information is missing, ask me up to 3 questions before you start.
