Context: I work with [type of data] (for example, patient demographics, disease prevalence, or treatment outcomes) at [your organization or role]. The data is de-identified. The main question is: [question you want to answer].
[data or column summary]
Goal: Find trends and gaps that can improve care or help prioritize public health actions, and present them to decision-makers.
Deliverable:
1. Quality check: missing data, sample bias, and limitations that affect the conclusions.
2. 5-8 findings (trends, differences between groups, correlations), each with the data point that supports it.
3. Actionable recommendations for healthcare providers or policymakers, with a priority and an indicator to measure their effect.
4. Further analyses worth running.
Criteria: Separate correlation from causation and state the confidence level of each finding, because these conclusions can shape care decisions. Work at the population level, with no conclusions about individual patients, and recommend validating the findings with clinical or epidemiology staff before acting. Flag any figure that doesn't come straight from the data as an estimate.
Format: Numbered sections; findings in a table with the columns Finding, Evidence, Confidence, and Implication.
If any essential information is missing, ask me up to 3 questions before you start.
