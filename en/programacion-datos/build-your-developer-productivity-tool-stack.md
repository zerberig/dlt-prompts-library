Context: I work as [your role] with [your stack and operating system]. These are the tools I use today: [tools you use today]. Where I lose the most time is [where you lose time] (for example: context switching, setting up environments, hunting for documentation, reviewing PRs, manual testing).
Goal: Win back time with a few well-chosen tools instead of piling on new apps.
Deliverable: 1) A diagnosis of my current workflow: what to keep, what's redundant, and what's missing. 2) 6 to 10 recommended tools by category (editor and AI coding assistants, terminal, test automation, task management, documentation, and focus), each with the problem it solves, key features, approximate cost, and a free alternative. 3) A 4-week adoption plan, one tool at a time. 4) 3 time management techniques that pair well with these tools.
Criteria: Prioritize what tackles my biggest time sinks. Use web search if you have it to confirm current features and pricing, and flag anything you can't confirm as an estimate.
Format: A table with the columns Category, Tool, Problem it solves, Key features, Cost, and Alternative; then the plan and the techniques as lists.
If any essential information is missing, ask me up to 3 questions before you start.
