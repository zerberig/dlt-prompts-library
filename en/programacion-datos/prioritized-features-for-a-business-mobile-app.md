Context: We want a mobile app for [your business]. It will be used by [app users] to [what they need to accomplish]. We already have these systems: [existing systems] (for example, CRM, ERP, payment gateway, or inventory).
Goal: Decide what to build first so we launch something useful without spending budget on features nobody uses.
Deliverable: 1) 15-20 possible features grouped by user goal. 2) RICE prioritization (reach, impact, confidence, effort), with the assumptions explained. 3) An MVP proposal of 5-7 features and why. 4) Integration points with our systems and what each one involves. 5) User stories for the MVP features.
Criteria: Start from real user needs, not from what competitors have. Flag reach and effort values as estimates, because they depend on data you don't have.
Format: A feature table with the columns Feature, User goal, Reach, Impact, Confidence, Effort, RICE score, and Integrations; then the MVP and user stories as bullets.
If any essential information is missing, ask me up to 3 questions before you start.
