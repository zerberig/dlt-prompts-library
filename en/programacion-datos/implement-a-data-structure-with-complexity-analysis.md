Context: I'm learning or reviewing data structures. I want to implement [data structure] in [language] (for example: a queue backed by a linked list, or a doubly linked list).
Goal: Understand how it works under the hood and have a clean implementation I can use as a reference or in a technical interview.
Deliverable: 1) A short explanation of the structure and when it beats the alternatives. 2) A complete implementation with the core operations (insert, delete, search, plus any specific to the structure) and comments on the non-obvious parts. 3) A time and space complexity table per operation. 4) Unit tests covering normal and edge cases (empty structure, a single element, duplicate elements). 5) A usage example and a practice exercise.
Criteria: Idiomatic code for the language, without falling back on the version its standard library already provides, so the logic is visible. Handle errors explicitly (for example, dequeuing from an empty queue). If there's a common optimization, explain it separately.
Format: Numbered sections; code and tests in separate blocks.
