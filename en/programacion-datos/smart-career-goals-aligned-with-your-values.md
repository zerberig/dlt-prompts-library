Context: I work as [your current role] and a year from now I'd like to [where you want to be]. What I value most in my work is [your values or priorities] (for example: autonomy, learning, stability, impact).
Goal: Turn broad aspirations into a few clear goals I can track and review every quarter.
Deliverable: 1) 3 SMART goals (specific, measurable, achievable, relevant, time-bound) and how each one connects to my values. 2) For each goal: a progress indicator, 3 quarterly milestones, and the first action for this week. 3) A 5-question quarterly review for adjusting the goals.
Criteria: Goals should depend mainly on me (for example, "lead the design of 2 features" rather than "get promoted"), so I can measure progress even if circumstances change. Point out if any goal competes with another for time or energy. 3 goals max, to stay focused.
Format: One table per goal with the columns SMART element and Description; then the milestones and the review as bullets.
If any essential information is missing, ask me up to 3 questions before you start.
