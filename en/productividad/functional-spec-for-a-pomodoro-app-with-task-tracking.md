Context: I want to build a Pomodoro timer app with task tracking for [the app's target audience]. I'll build it with [platform or development tool]. What should set it apart is [main differentiator].
Goal: A clear spec I can hand to a developer or an AI coding tool to build a working first version.
Deliverable:
1. The problem and primary user in one paragraph.
2. MVP features (configurable timer, task list, assigning pomodoros to tasks, estimated vs. actual, history) and features for a phase 2.
3. Main user flows, step by step.
4. Screens with their elements and states: empty, running, paused, and completed.
5. Data model with entities and fields.
6. Testable acceptance criteria for each feature.
7. Accessibility, notifications, and offline considerations.
Criteria: Prioritize an MVP that can be built in a few weeks; everything else goes to phase 2. Write acceptance criteria in "Given / When / Then" format. Flag the open decisions I need to make.
Format: A document with numbered sections and tables where they help, 800 to 1,200 words.
If any essential information is missing, ask me up to 3 questions before you start.
