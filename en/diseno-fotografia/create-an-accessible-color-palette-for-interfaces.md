Context: I'm designing [type of project] (app, website, or dashboard) with [base color] as the main brand color. I want the interface to feel [personality or mood].
Goal: A palette ready for interface use that meets WCAG 2.2 Level AA contrast guidelines, so text and controls are readable for everyone.
Deliverable: 1) A palette with primary, secondary, accent, neutrals (5 to 7 shades), and status colors (success, warning, error, info), each with HEX and RGB. 2) A table of text-and-background pairs with their contrast ratio and whether each passes AA for normal text (4.5:1), large text (3:1), and UI components (3:1). 3) Combinations to avoid. 4) A dark mode variant. 5) Usage rules: which color for buttons, links, backgrounds, and alerts.
Criteria: Calculate contrast using the relative luminance formula and note that the ratios should be confirmed with a contrast checker before implementation. Status states shouldn't rely on color alone: suggest an icon or label to go with each.
Format: Tables for the palette and the pairs; usage rules as bullets.
