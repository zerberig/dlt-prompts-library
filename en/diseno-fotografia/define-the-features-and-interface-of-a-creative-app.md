Context: I'm designing [type of creative tool] (for example, a storyboarding, animated prototyping, or mood board app) for [target users]. Their main problem today is [users' main problem].
Goal: Define a simple, intuitive tool people can use without training, one that doesn't fill up with unnecessary features.
Deliverable: 1) The 7 essential features ranked by importance, with why each matters to this user. 2) The main workspace described as a text wireframe: screen areas, which tools are always visible, and which are tucked away. 3) The 3 key flows step by step (for example, creating a project, building a sequence, exporting and sharing). 4) Shortcuts and gestures that save time. 5) What's deferred to future versions and why. 6) Basic accessibility considerations.
Criteria: Every decision justified by the user's task. If a feature doesn't serve the main flow, it moves to a future version.
Format: Numbered sections with bullets; flows as numbered lists.
If any essential information is missing, ask me up to 3 questions before you start.
