Context: My brand is [your brand] and I want to benchmark myself on [platform] against these direct competitors: [competitors to compare].
Goal: Know where I'm ahead or behind using data I can collect myself, and decide what to improve first.
Deliverable: 1) A template to manually collect each account's public data over 4 weeks: followers, posting frequency, formats, visible engagements per post, and response time to comments. 2) How to calculate an engagement rate that's comparable across accounts of different sizes. 3) How to read the results: which gaps matter and which are noise. 4) How to set my top 3 improvement priorities once I have the data.
Criteria: Use only public, observable metrics, because I don't have access to competitors' private analytics. If you have web search, review these accounts' recent public information and flag any figure you can't confirm as an estimate.
Format: The template as a table with one row per competitor; everything else in short sections. 600 words max.
If any essential information is missing, ask me up to 3 questions before you start.
