Context: I make budget decisions using data from [platforms] and [web analytics tool]. Here's how tracking is set up today: [current setup] (pixel or conversions API, UTM parameters, events, attribution windows). I suspect that [perceived problem] (for example, the platforms report more sales than my store records).
Goal: Find out how reliable my data is and what to fix before I rely on it, because more accurate, granular data leads to better decisions.
Deliverable: 1) An audit by area: link tagging, conversion events, duplicates, attribution, data lost to privacy settings or blockers, and consistency across sources. 2) For each area: how to check it, warning signs, and the fix. 3) Why platform numbers and web analytics never fully match, and what gap is reasonable. 4) More robust measurement options (incrementality tests, media mix models, "how did you hear about us?" surveys) and when each is worth it. 5) The 5 priority fixes, ranked by impact and effort.
Criteria: Plain language: explain each technical term the first time it appears. If you have web search, check each platform's current documentation. Flag as an estimate any figure you can't back up with a source.
Format: An audit table with the columns Area, How to check, Warning sign, and Fix; everything else in sections.
If any essential information is missing, ask me up to 3 questions before you start.
