Context: My team runs social media for [your brand or department] on [platforms you use] and everyone calculates metrics differently.
Goal: Have a single reference sheet so everyone measures the same way and reports can be compared month over month.
Deliverable: A reference sheet with 12-15 KPIs grouped into reach, engagement, community, traffic, conversion, and customer care. For each: a one-line definition, formula, where the data comes from on each platform, which decision it supports, and a common calculation mistake. At the end, the 5 you recommend as primary for this goal: [main social media goal].
Criteria: Simple, consistent formulas. When platforms define a metric differently (for example, reach versus impressions or views), explain how to normalize it. If you have web search, check the current metric names on each platform.
Format: A table with the columns KPI, Definition, Formula, Source, Decision it supports, and Common mistake; then the list of the top 5.
If any essential information is missing, ask me up to 3 questions before you start.
