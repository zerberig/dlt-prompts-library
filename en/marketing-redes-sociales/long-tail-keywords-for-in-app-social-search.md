Context: I post content about [your industry or category] on [platform], where more and more people search directly in the search bar. My audience is [target audience].
Goal: I want to show up when my audience searches for specific solutions inside the app, instead of relying only on the algorithm to surface me.
Deliverable: 1) Twenty long-tail keywords (3-6 word phrases) grouped by intent: learn, compare, solve a problem, and buy. 2) For each group, a post idea that answers those searches. 3) Where to place keywords on [platform]: profile name, bio, caption, on-screen text, subtitles, alt text, or titles, as applicable.
Criteria: Use phrases the way a real person in my region would type them. If you have web search, lean on autocomplete suggestions and current trends. Flag as an estimate any search volume you can't back up with a source.
Format: A table with the columns Keyword, Intent, and Post idea; then the placement guide as bullets.
If any essential information is missing, ask me up to 3 questions before you start.
