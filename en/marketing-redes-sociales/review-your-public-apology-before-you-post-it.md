Context: My brand [your brand] made this mistake: [what happened and who it affected]. This is the apology draft we plan to post: [your apology draft]. We'll publish it on [platforms].
Goal: I want an apology that sounds sincere, takes responsibility, and explains what we'll do, so it rebuilds trust instead of fueling criticism.
Deliverable: 1) An evaluation of the draft against 5 criteria: clearly acknowledges the mistake, takes responsibility without blaming others, shows empathy for those affected, lays out concrete actions, and avoids a defensive tone. Score each one and point out the problem phrases. 2) A corrected version. 3) Adaptations for each platform (main post, a short version for replies, and a brief script if it will be on video). 4) Three model replies for critical comments.
Criteria: Avoid lines like "we're sorry if anyone was offended", because they come across as evasive. Only promise actions we can deliver. If there are legal implications, recommend reviewing it with legal counsel before posting.
Format: The evaluation in a table with the columns Criterion, Score, and Comment; then each version in its own block.
If any essential information is missing, ask me up to 3 questions before you start.
