Context: I manage the [your brand or profile] account on [platform]. We received this copyright complaint: [complaint details] (who is complaining, which content, and whether it came as a message or a formal platform notice). About where the content came from, we know that [content source] (we made it, we licensed it, we took it from the internet, etc.).
Goal: I want to resolve the complaint correctly and quickly, protect the account, and keep it from happening again.
Deliverable: 1) The available options (take the content down, request a license, give credit, file a counter-notice) with pros and cons for my case. 2) A respectful reply to the person complaining. 3) A checklist for using third-party content from now on: music, images, and user content.
Criteria: Explain the concepts in plain language. If you have web search, check [platform]'s current process for complaints and counter-notices. Make clear this is general information, not legal advice, and recommend consulting an intellectual property lawyer if money is at stake or a lawsuit is threatened.
Format: Options in a table with the columns Option, When it makes sense, and Risks; then the message and the checklist.
If any essential information is missing, ask me up to 3 questions before you start.
