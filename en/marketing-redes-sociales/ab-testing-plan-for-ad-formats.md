Context: I advertise [your product or service] on [platform] with a monthly budget of [monthly budget]. Today I mostly use [current format], and my campaign objective is [campaign objective].
Goal: Learn from data which format (static image, carousel, short video, collection, or another available option) delivers the best results for my objective, instead of going on gut feeling.
Deliverable: 1) Four prioritized A/B tests, each with a hypothesis, the variable that changes, what stays the same, the primary metric, and the criterion for declaring a winner. 2) Suggested budget and duration per test to get reliable results. 3) The best order to run them in and why. 4) A log template to record results and learnings.
Criteria: One variable per test, so you know what caused the difference. If you have web search, check whether the platform has a native testing tool and explain how to use it. Flag as an estimate any figure you can't back up with a source.
Format: A table with the columns Test, Hypothesis, Variant A, Variant B, Metric, and Success criterion; everything else as bullets.
If any essential information is missing, ask me up to 3 questions before you start.
