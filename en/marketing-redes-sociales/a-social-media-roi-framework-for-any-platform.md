Context: I manage social media for [your business or organization] on [platforms]. My social goals are [main goals], and the investment includes [costs involved] (ads, team hours, tools, production, creator fees).
Goal: I want a single framework to calculate the return of any platform, one I can present to leadership and that includes value that doesn't turn directly into sales.
Deliverable: 1) How to calculate the real total cost, including team time. 2) How to assign monetary value to each type of result: attributed sales, leads, customer-service savings, and reusable content. 3) How to record qualitative value (brand perception, comment quality, unprompted mentions) with a simple, repeatable scale. 4) The final formula and a worked example with illustrative numbers. 5) The most common measurement mistakes and how to avoid them.
Criteria: The framework should apply the same way to every platform so they can be compared. Clearly separate proven value from estimated value and explain the assumptions behind each estimate. Flag as an estimate any figure you can't back up with a source.
Format: Numbered sections; the calculation in a table with the columns Component, Data source, Formula, and Value type (proven or estimated).
If any essential information is missing, ask me up to 3 questions before you start.
