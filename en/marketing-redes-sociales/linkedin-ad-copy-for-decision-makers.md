Context: My company offers [your B2B product or service] to [target industry]. I want to run LinkedIn ads targeting these job titles: [decision-maker job titles].
Goal: Ad copy that speaks to each role's specific problems in order to achieve [ad objective].
Deliverable: 1) For each role, their main concern related to my solution and the benefit they care about most. 2) Per role, 3 single-image ad variants: intro text (150 characters max before the cutoff), headline (70 characters max), and call to action. 3) A script for a 5-card carousel ad that shows industry know-how. 4) Which variant to test first and why.
Criteria: Industry language, no empty jargon or superlatives. Use data or results only if I provide them; where one would be needed, leave a gap marked "to be completed". If you have web search, check LinkedIn's current character limits.
Format: One section per role; the carousel as a table with the columns Card, Copy, and Suggested visual.
If any essential information is missing, ask me up to 3 questions before you start.
