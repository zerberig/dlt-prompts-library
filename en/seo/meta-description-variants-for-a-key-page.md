Write 3 meta descriptions for my page about [page topic], aimed at [target audience], with the main keyword [keyword]. What makes this page different is: [value proposition].
Each option should be 120-155 characters so it doesn't get cut off in search results, include the keyword naturally in the first half, accurately describe what the person will find, and end with an invitation to click. Use a different angle for each: benefit, answering a question, and a concrete fact.
Deliver a table with Option, Text, Character count, and Angle, and tell me which one you'd test first.
