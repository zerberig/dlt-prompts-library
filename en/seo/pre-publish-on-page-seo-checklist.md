I publish [type of pages] on [platform or CMS]. Create an on-page SEO checklist to run before publishing, split into: intent and content, metadata (title, meta description, URL), headings, images and media, internal and external links, structured data, mobile and speed, and call to action. Each item should be a yes-or-no question, and if my platform has a specific place to set it, say where. 25 items max, ordered from most to least important within each block, so I can get through it in 10 minutes per page. Deliver the list with Markdown checkboxes.
