Context: My site is about [your site topic] and these are my most important pages: [list of key pages].
Goal: I want my pages to show up more often in the special search features (featured snippets, related questions, rich results, and answers generated by AI-powered search), not just the blue links.
Deliverable: 1) Which search features are realistic for each type of page I have. 2) For each key page, 2 or 3 specific changes with a before-and-after example (a direct-answer paragraph, a table, a list of steps, an FAQ block, or a type of structured data). 3) How to measure whether it worked.
Criteria: Examples written for my topic, not generic ones. Make clear that no technique guarantees a placement. If you have web search, confirm which rich results are still supported, since search engines retire some of them regularly.
Format: Sections with headings; before-and-after examples in separate blocks.
If any essential information is missing, ask me up to 3 questions before you start.
