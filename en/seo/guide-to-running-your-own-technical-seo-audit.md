Context: I have a [type of site] built on [platform or CMS], with around [approximate number of pages] pages. I'm not a developer, but I can follow instructions and use free tools.
Goal: I want to run a technical audit myself to find what's stopping my pages from being crawled, indexed, and loaded properly.
Deliverable: A step-by-step guide in the order it makes sense to check things: indexing in Search Console, robots.txt and sitemap, status codes and redirects, duplicate content and canonical tags, speed and Core Web Vitals, the mobile version, HTTPS, and structured data. For each step: which tool to use, what to look for, what a problem looks like, and how to fix it on my platform.
Criteria: Concrete instructions that assume no coding knowledge. Point out which problems I can fix myself and which need a developer. If you have web search, confirm that the tools and menus you mention still exist.
Format: Numbered steps with subheadings; at the end, a table template for logging findings with the columns Issue, Affected URL, Priority, and Owner.
If any essential information is missing, ask me up to 3 questions before you start.
