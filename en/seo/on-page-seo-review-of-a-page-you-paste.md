Context: This is a page on my site that I want to rank for [target keyword]. Page content: [page content] (SEO title, meta description, URL, headings, body text, image alt text, and links).
Goal: I want to know what this page is missing to compete, and fix it today.
Deliverable: 1) A 1–5 score for each element: SEO title, meta description, URL, H1 and heading structure, topic coverage against search intent, readability, internal links, images, and call to action. 2) For every element scoring below 4, a corrected version ready to paste. 3) The 3 highest-impact changes if I only have an hour.
Criteria: Judge against the keyword's real search intent, not just whether the keyword appears. Point out what's excessive as well as what's missing. Fixes should keep the original tone.
Format: A table with the columns Element, Score, Problem, and Fix; then the 3 priority changes as a numbered list.
If any essential information is missing, ask me up to 3 questions before you start.
