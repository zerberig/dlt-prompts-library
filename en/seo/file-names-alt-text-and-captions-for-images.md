Context: I'm about to upload these images to a page about [page topic]. Here's a description of each one: [list of images].
For each image, write: a lowercase file name with hyphens and no special characters; alt text of up to 125 characters describing what's shown for someone who can't see it; and a short caption that adds context.
Use the keyword only where it naturally describes the image, because alt text is first and foremost for accessibility. If an image is purely decorative, say it should have an empty alt.
Format: A table with Image, File name, Alt text, and Caption.
